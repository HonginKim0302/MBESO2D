# Generated Results

The example solvers write run reports and optional MAT result files to this
directory unless an explicit output path is supplied. Typical names are:

```text
mbeso_run_report_YYYYMMDD_HHMMSS.txt
mbeso_fixed_solid_run_report_YYYYMMDD_HHMMSS.txt
mbeso_fixed_solid_result_YYYYMMDD_HHMMSS.mat
```

Generated files are intentionally excluded from version control. Numerical
release baselines and representative figures are stored in `validation/`.
