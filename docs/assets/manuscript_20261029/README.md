## Submitted composition

[Submitted_figures.pptx](Submitted_figures.pptx) preserves the author-supplied
PowerPoint figure source. Panel lettering, arrows, connectors, callouts,
inset placement and other manual annotations belong to that composition.
The numerical reproduction scripts generate editable curves, axes, bars and
legends from the supplied records; these PNG previews do not replace the
PowerPoint source or certify pixel-identical slide composition.

Figure 6(b) combines the first-ten-update material histories with locations
in the update-10 layout. The optional
`reproduction/submission_20261029/RUN_SUBMITTED_ASSIGNMENT.m` reconstructs
these records as native MATLAB graphics. It preserves the actual states and
the shared material palette; its layout is not a pixel-identical copy of
the manually assembled PowerPoint panel.

[Optional native Figure 6(b) preview](reproduced/Fig06_b.png) is supplied
separately from the eight main numerical graphs and their two zooms below.
