Portable publication of Revision 5 review experiments

1. engine/src: the five numerical source files are copied byte-for-byte from
   Revision 5. Production src/ is neither overwritten nor required to expose
   diagnostic callbacks. Source hashes are in source_provenance.csv.
2. run_revision5_histories: numerical observation, pilot identity, independent
   replay, trajectory and deadband calculations are retained. Removed only
   development-directory archive loads/comparisons; mark them not run/NaN.
   Added initial10 mode so the first-ten calculation can run separately.
3. run_solver_regression_checks: adapt to the current public solver, which has
   no diagnostic callback. Compare all 20 scalar response histories and the
   final density/material/displacement/centroidal-stress fields; do not claim
   access to the public solver's intermediate material maps. Bridge meshes
   are reduced to 64 by 16 for this smoke-scale regression only.
4. run_stress_recovery_study: default is full-domain reporting. Historical
   exclusion-width calculations require an explicit optional config field;
   they are not used by the added review analyses.
5. run_review_experiments: new scoped entry point, fresh timestamped outputs,
   deterministic case selection, material-specific positive utilization,
   path restoration and explicit completion/termination metadata.
6. No FE matrices, loads, material strengths, optimization scores, filter
   operations or baseline material-classification rules were changed during
   publication. Reexecution is separate from archived plot-data replay.
7. Table 10 endpoint extension (2026-10-14): append the 0.05, 0.5 and 5 MPa
   deadband cases to review_suite_cases without renumbering earlier cases.
   Select runs by group/run_id, rather than fixed index ranges. Sensitivity
   now contains the baseline plus 16 variants (17 runs); all contains three
   baselines, 16 variants and three continuations (22 endpoint runs), followed
   by the existing audits and histories. The separate deadband_extension mode
   recomputes only the baseline plus the three added first-stop endpoints.
   This adds experiment declarations and entry points, not solver changes.
